# UrbanFootprint AI

## Project Overview

UrbanFootprint AI is an AI-powered geospatial
system designed to extract building footprints
from satellite and aerial imagery.

## Objectives

- Satellite image processing
- AI-based building segmentation
- Building footprint extraction
- GIS-ready vector generation
- Urban geospatial analysis

## Technologies

- Python
- PyTorch
- OpenCV
- Rasterio
- GeoPandas
- FastAPI
- React
